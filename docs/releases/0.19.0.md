# earthcarekit 0.19.0 (September 30, 2026)

This release fixes geo-based data searches with `ecdownload` when defining areas extending across the dateline (Issue #10).

## Changelog

### Breaking Changes
- Ensure `pystac_client` compatible intersects in `ecdownload` (#10)
- Treat 2-element tuples in `filter_index()` like `slice()`
- Disable downloads by default in `ecload()` and `eclazy()`

### New Features
- Add default plot settings for POLIPHON variables
- Add decorators for method execution flow control in classes modelling data processors
- Add matplotlib-compatible percentile-based normalization classes
- Add type narrowing functions
- Add option to get filepath with `ecload()` and `eclazy()`
- Prefer "label" over "long_name" dataset attribute
- Add MISSING sentinel
- Add `sentinels` module including UNSET sentinel
- Add round to step functions
- Add new CLI tool `ecki` (EarthCareKit Interface)

### Bug Fixes
- Ensure new copy of default norm
- Prevent `PercentileLogNorm` error with all-nan data
- Accept type `pathlib.Path` in `read_product()`
- Apply rgb composite ranges also to data outside time range
- Resolve wrong first column size bug in `create_column_figure_layout()`
- Remove repeated key
- Support saving of `SubFigure`s in `save_plot()`
- Resolve `value_range` bug in `ProfileFigure`
- Warn and handle zero-duration time ranges in curtain plots
- Ensure correct `Profile` array shapes
- Support single-sample datasets in curtain figure height line overlays

### Maintenance
- Remove sentinel from `get_first()`
- Use new UNSET sentinel
- Rename `perform_anom_depol_statistics()` to `compute_anom_depol_statistics()`
- Add merges section in release notes
- Change docs workflow triggers to dispatch and releases
- Fix date in release workflow

### Documentation
- Update example in `ecquicklook_psc()` docstring
- Unify and improve docstrings
- Add `workflow` module and improve docstrings
- Fix typo in `search_files_by_regex()` docstring
- Add API reference for `utils.time` and `utils.logging` modules
